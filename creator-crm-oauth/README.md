# DisonNans Creator CRM

DisonNans Creator CRM is a personal, locally hosted creator dashboard for managing streaming analytics and highlights.

## YouTube integration

The application uses Google OAuth 2.0 to read the owner's YouTube Analytics data. Access is read-only and is used to display channel analytics inside the local CRM dashboard.

## Data handling

The CRM runs locally on the owner's computer. OAuth credentials and analytics data are stored locally and are not sold or shared with third parties.
